# Shishir Consultants

Website for Shishir Consultants Pvt. Ltd., an interior design, architecture, construction, and maintenance firm based in Patna, Bihar.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run build
```

## Deployment

The `main` branch deploys to [shishir-interior.vercel.app](https://shishir-interior.vercel.app).
